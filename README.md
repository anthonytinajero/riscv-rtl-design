# RISC-V Processor Design | RTL Development

A hands-on exploration of RISC-V processor architecture,
digital logic, and RTL design using SystemVerilog.

## Overview

This repository documents my progress in learning
processor architecture and hardware design through
the implementation of individual RISC-V CPU components.

As an Electrical Engineering student at the University
of Houston, I am developing a deeper understanding of
how processors operate at the register-transfer level (RTL).

Through this project, I am gaining practical experience
with combinational and sequential logic, hardware
description languages, and fundamental CPU architecture.

My current focus is implementing and understanding
individual processor components, with the long-term
goal of integrating them into a functional RISC-V CPU.

## Project Objectives

- Develop proficiency in SystemVerilog and RTL design.
- Understand the architecture of a RISC-V processor.
- Implement fundamental CPU components.
- Learn hardware simulation and verification techniques.
- Progress toward a complete single-cycle RISC-V processor.
